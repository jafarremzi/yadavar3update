# یادآور من

دستیار صوتی فارسی برای یادداشت و یادآوری (اندروید، Kotlin + Jetpack Compose).
بگویید «فردا ساعت سه بعدازظهر جلسه دارم»؛ برنامه متن را نشان می‌دهد، تاریخ و ساعت را استخراج می‌کند، از شما تأیید می‌گیرد و یک اعلان واقعی و پایدار برای آن زمان ثبت می‌کند.

## ویژگی‌ها
- ضبط صدا با میکروفون و تشخیص گفتار فارسی (`fa-IR`) با سرویس تشخیص گفتار خود سیستم (بدون کلید API و هزینه)
- نمایش وضعیت‌ها: آماده شنیدن، در حال گوش دادن، در حال پردازش، ثبت شد
- متن تشخیص‌داده‌شده قابل ویرایش است؛ پیش از ذخیره، عنوان، تاریخ و ساعت برای تأیید نشان داده می‌شود
- موتور تحلیل زمان فارسی (ماژول مستقل و تست‌شده): «پنج دقیقه دیگر»، «نیم ساعت دیگر»، «فردا صبح»، «امشب ساعت نه»، «پس‌فردا ساعت ده صبح»، روز هفته، تاریخ شمسی (مثل «۷ آبان» یا `1405/8/7`)، ارقام فارسی و لاتین
- اگر ساعت مبهم باشد («فردا ساعت سه»: صبح یا بعدازظهر؟) زمان پیشنهادی نمایش داده و تأیید گرفته می‌شود؛ ثبت یادآوری در گذشته مسدود است
- ذخیره پایدار با Room؛ یادآوری با AlarmManager و اعلان، بازیابی پس از ریبوت/به‌روزرسانی/تغییر ساعت
- یادآوری تکرارشونده (روزانه/هفتگی)، ویرایش، لغو، حذف، «انجام شد»، جست‌وجو و فیلتر
- **ویرایش و حذف** هر یادداشت (از جمله یادداشت‌های صوتی) هم در صفحهٔ اصلی و هم در «همه یادداشت‌ها»؛ حذف با تأیید
- **پک‌ها**: کارها را در گروه‌هایی مثل «دانشگاه» یا «سایت» نگه دارید (هر کار در یک پک). پک «عمومی» همیشه هست و قابل حذف نیست؛ کارهای قبلی و کارهای بدون پک در آن قرار می‌گیرند. در ویرایشگر پک انتخاب می‌شود، در «همه یادداشت‌ها» بر اساس پک فیلتر می‌شود و صفحهٔ «پک‌های کارها» برای ساخت، تغییر نام، حذف و نمایش هر پک است. با حذف یک پک، کارهایش حذف نمی‌شوند و به «عمومی» می‌روند.
- **ظاهر نئومورفیک تیره** (سرمه‌ای با تاکید فیروزه‌ای، کارت‌های برجسته، دکمه‌های گرد، میکروفون با موج صدای متحرک) روی همهٔ صفحه‌ها؛ فونت وزیرمتن داخل برنامه است. تم روشن و «مطابق سیستم» (وقتی گوشی روشن است) ظاهر ساده‌تر Material دارند.
- **آیکن خودکار پک‌ها** از روی نام: دانشگاه ← کلاه فارغ‌التحصیلی، سایت ← کره زمین، عمومی ← شبکهٔ چهارتایی، و نیز کار، خرید، خانه، ورزش، کتاب، سلامت، مالی، سفر، غذا، موسیقی، ماشین، خانواده و … (نام ناشناخته ← پوشه). در دیالوگ ساخت/تغییر نام پک، آیکن هم‌زمان با تایپ نام نمایش داده می‌شود.
- بخش «سازنده» در تنظیمات با لینک اینستاگرام
- تم تیره (پیش‌فرض)، روشن یا مطابق سیستم؛ RTL کامل؛ تاریخ شمسی در رابط

## دستورهای صوتی پک
| بگویید | نتیجه |
|---|---|
| «یک پک با عنوان دانشگاه بساز» / «پک مربوط به کارهای دانشگاه رو بساز» / «یک پک برای کارهای سایت درست کن» / «پک کارهای عمومی را بساز» | پک ساخته می‌شود (اگر از قبل باشد، پیام «از قبل وجود دارد») |
| «فردا تحویل پروژه، به کارهای دانشگاه اضافه کن» | متن کار (بدون عبارت دستور) در ویرایشگر باز می‌شود و پک «دانشگاه» از قبل انتخاب شده است؛ زمان و متن را مثل همیشه تأیید می‌کنید |
| همان جمله برای پکی که وجود ندارد | قبل از ساخت پک از شما تأیید گرفته می‌شود («ساخت پک و ادامه» یا «ادامه در عمومی») |

نکته‌ها:
- عبارت «به کارهای X / به پک X اضافه کن» باید **در انتهای جمله** بیاید (فعل‌های دیگر: بذار، ثبت کن، ذخیره کن، قرار بده). نام پک با «کارهای دانشگاه»، «پک دانشگاه» و «دانشگاه» یکسان تطبیق داده می‌شود.
- اگر جمله‌ای شبیه دستور باشد ولی نه «پک / کارهای …» در آن باشد و نه پکی با آن نام وجود داشته باشد (مثل «سبد رو توی ماشین بذار»)، مثل یک یادداشت عادی رفتار می‌شود.
- جملهٔ «این کار را به کارهای دانشگاه اضافه کن» بدون متن کار، فقط پیام راهنما می‌دهد (کار باید در همان جمله گفته شود).

## دریافت APK (از GitHub Actions)
1. کد را در یک مخزن GitHub بگذارید:
   ```bash
   git init && git add . && git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/<USER>/<REPO>.git
   git push -u origin main
   ```
2. در مخزن: **Actions ← Android CI**. با Push خودکار اجرا می‌شود؛ برای اجرای دستی **Run workflow** را بزنید.
3. پس از اتمام موفق (علامت سبز): همان اجرا را باز کنید ← پایین صفحه **Artifacts** ← **YadAvar-debug-apk** را دانلود کنید (یک zip که فایل `YadAvar-debug.apk` داخل آن است).
4. فایل را روی گوشی منتقل کنید ← باز کنید ← در صورت پرسش، «نصب از منبع ناشناس» را برای همان برنامه مرورگر/فایل‌منیجر مجاز کنید ← نصب.
5. اگر build شکست خورد، Artifact با نام **build-reports** شامل گزارش تست و خطا است.

### انتشار نسخه جدید (Release)
```bash
git tag v1.0.1 && git push origin v1.0.1
```
با Push تگ `v*`، پس از موفقیت build و تست‌ها یک GitHub Release همراه **APK امضاشدهٔ Release** ساخته می‌شود.

#### تنظیم امضای Release (یک‌بار)
در GitHub: Settings ← Secrets and variables ← Actions ← New repository secret؛ **نام‌ها باید دقیقاً این‌ها باشد**:

| Secret | مقدار |
|---|---|
| `KEYSTORE_BASE64` | خروجی base64 **کل فایل** `.jks` (در یک خط) |
| `KEYSTORE_PASSWORD` | رمز keystore |
| `KEY_ALIAS` | نام alias (با `keytool -list -keystore release.jks` دیده می‌شود) |
| `KEY_PASSWORD` | رمز کلید (اگر خالی بگذارید همان رمز keystore استفاده می‌شود) |

ساخت keystore و base64 (لینوکس/مک):
```
keytool -genkeypair -v -keystore release.jks -alias yadavar -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.jks          # مک: base64 -i release.jks | tr -d '\n'
keytool -list -keystore release.jks   # برای دیدن alias و تست رمز
```
ویندوز (PowerShell): `[Convert]::ToBase64String([IO.File]::ReadAllBytes("release.jks")) | Set-Clipboard`

Workflow قبل از ساخت، Secretها و keystore را با `keytool` بررسی می‌کند و علت دقیق مشکل را چاپ می‌کند. روی Push معمولی، اگر کلید معتبر نباشد با هشدار و با کلید دیباگ ساخته می‌شود؛ روی Tag (انتشار) برای جلوگیری از انتشار اشتباه، build شکست می‌خورد. **فایل keystore را هرگز در مخزن نگذارید و از آن نسخهٔ پشتیبان امن نگه دارید**؛ با گم شدنش دیگر نمی‌توان آپدیت هم‌امضا منتشر کرد.

## معماری
```
app/src/main/java/app/yadavar/
  time/      موتور تحلیل زمان فارسی، تقویم شمسی، قالب‌بندی (بدون وابستگی به اندروید)
  pack/      تحلیل دستورهای صوتی پک و تعیین آیکن پک از روی نام (بدون وابستگی به اندروید، تست‌شده)
  data/      Room (NoteEntity/PackEntity/Dao/Database)، Repository، تنظیمات
  reminder/  AlarmManager، BroadcastReceiverها (آلارم، بوت)، اعلان‌ها
  speech/    پوشش SpeechRecognizer
  ui/        Compose: خانه، تأیید/ویرایش، همه یادداشت‌ها، پک‌ها، تنظیمات؛ MainViewModel
           Neo.kt (سیستم طراحی نئومورفیک)، AppIcons.kt (آیکن‌های وکتور Material)، PackIconVectors.kt، AppInfo.kt
```
دیتابیس: نسخهٔ ۲ (جدول `packs` + ستون `notes.packId`؛ `MIGRATION_1_2` داده‌های قبلی را نگه می‌دارد و همه را به پک «عمومی» می‌برد).
نسخه‌ها: Kotlin 2.0.21، AGP 8.7.3، Gradle 8.9، Compose BOM 2024.10.01، Room 2.6.1، minSdk 26، targetSdk 34.

## وضعیت واقعی تست‌ها (صادقانه)
| مورد | وضعیت |
|---|---|
| موتور تحلیل زمان فارسی، تقویم شمسی (رفت‌وبرگشت ۲۰۲۰–۲۰۳۲)، محاسبه تکرار، تحلیل دستورهای صوتی پک، تعیین آیکن پک | **اجرا شد و موفق بود** (۶۸ تست با کامپایلر Kotlin 2.0.21 روی JVM، با یک شیم ساده به‌جای JUnit) |
| کامپایل Gradle/Compose/Room، ساخت APK | **اجرا نشد** — در محیط ساخت این پروژه به Android SDK و سرورهای Google/Maven دسترسی نبود؛ اولین اجرای GitHub Actions اولین کامپایل واقعی است |
| ظاهر نئومورفیک و همهٔ صفحه‌های Compose (سایه‌ها، رنگ‌ها، فونت، آیکن‌های وکتور، موج میکروفون، نوار پیشرفت) | **کامپایل و روی گوشی دیده نشد**؛ فقط پالت با یک رندر آزمایشی سنجیده شده. اولین اجرای CI اولین کامپایل واقعی است و ظاهر باید روی گوشی بازبینی شود |
| Migration نسخه ۱←۲ دیتابیس (Room)، دیالوگ‌ها و جریان دستورهای صوتی در ViewModel | **اجرا و کامپایل نشد** (فقط بازبینی دستی کد)؛ باید روی گوشی با یک نسخهٔ نصب‌شدهٔ قبلی (برای تست مهاجرت) آزمایش شود |
| تست‌های واحد در Gradle (همان فایل‌های بالا با JUnit واقعی) | اجرا نشد (در CI اجرا می‌شود) |
| مجوز میکروفون (قبول/رد)، تشخیص گفتار فارسی، اعلان، آلارم یک‌دقیقه‌ای، ریبوت، Force Stop، قفل صفحه | **روی هیچ دستگاه/شبیه‌ساز اجرا نشد** — باید روی گوشی واقعی آزمایش شود |

چک‌لیست آزمایش روی گوشی:
1. مجوز میکروفون را قبول و رد کنید (در رد، پیام و دکمه «باز کردن تنظیمات برنامه» نمایش داده می‌شود).
2. بگویید «یک دقیقه دیگر یادآوری کن چای بخورم» ← تأیید ← پس از یک دقیقه اعلان بیاید و لمس آن یادآوری را باز کند.
3. برنامه را ببندید و باز کنید؛ یادداشت‌ها باید بمانند.
4. گوشی را ریبوت کنید؛ یادآوری‌های آینده باید همچنان کار کنند.
5. اینترنت را قطع کنید و ضبط کنید (خطای قابل فهم یا کارکرد آفلاین، بسته به سرویس گوشی).
6. مجوز اعلان و «آلارم دقیق» را رد کنید و پیام‌ها را ببینید.
7. **مهاجرت**: نسخهٔ قبلی را با چند یادداشت نصب کنید، سپس نسخهٔ جدید را *روی آن* نصب کنید (بدون حذف)؛ یادداشت‌ها باید بمانند و همه در پک «عمومی» باشند.
8. بگویید «یک پک با عنوان دانشگاه بساز»، سپس «فردا تحویل پروژه، به کارهای دانشگاه اضافه کن»؛ ویرایشگر با پک «دانشگاه» باز شود. دوباره با پکی که وجود ندارد امتحان کنید و دیالوگ تأیید را ببینید.
10. ظاهر: سایه‌های کارت‌ها (روی اندروید ۸ و ۹ سایهٔ بلور نمایش داده نمی‌شود و فقط خود سطح دیده می‌شود)، خوانایی متن‌ها، انیمیشن موج هنگام ضبط، و اینکه تم روشن هنوز سالم است.
11. در تنظیمات ← «سازنده» دکمهٔ اینستاگرام باید صفحه را باز کند.
9. یادداشتی بسازید، از صفحهٔ اصلی با دکمهٔ حذف پاکش کنید (باید تأیید بخواهد)؛ پکی را حذف کنید و ببینید کارهایش به «عمومی» رفتند.

## محدودیت‌های واقعی اندروید (تضمین نمی‌دهیم)
- **تشخیص گفتار فارسی** به سرویس نصب‌شده روی گوشی (معمولاً Google) و اغلب به اینترنت وابسته است؛ آفلاین‌بودن تضمین نمی‌شود. اگر سرویس یا زبان فارسی نباشد، خطای واضح نمایش داده می‌شود و «یادداشت متنی» در دسترس است.
- **Force Stop**: اندروید همه آلارم‌های برنامه را پاک می‌کند تا کاربر دوباره برنامه را باز کند؛ با بازکردن برنامه، یادآوری‌ها دوباره برنامه‌ریزی و موارد از دست‌رفته به‌صورت «یادآوری از دست رفته» نمایش داده می‌شوند.
- **آلارم دقیق** در اندروید ۱۲+ نیاز به اجازه کاربر دارد (تنظیمات ← مجوزها)؛ بدون آن آلارم تقریبی ثبت می‌شود و ممکن است دقایقی دیر برسد. **اعلان‌ها** در اندروید ۱۳+ نیاز به مجوز دارند.
- بعضی سازنده‌ها (سامسونگ، شیائومی، هوآوی و…) برنامه‌های پس‌زمینه را شدیداً محدود می‌کنند؛ معافیت از بهینه‌سازی باتری کمک می‌کند ولی تضمین کامل نیست.
- `allowBackup` خاموش است؛ پس از حذف برنامه یادداشت‌ها پاک می‌شوند.
- چرخش صفحه/خروج از برنامه ضبط جاری را لغو می‌کند (میکروفون پس‌زمینه فعال نمی‌ماند).
